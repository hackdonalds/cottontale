# Third-party figures (CC0)

Rigged, animated source models for the miniatures. All are public domain (Creative Commons
Zero 1.0); credit is not required but given gladly. `assets/blender/imported.py` poses them,
bakes their colours into the vertices and scales them to the table.

- `kaykit-adventurers/` — KayKit Adventurers Character Pack 1.0 by Kay Lousberg
  (www.kaylousberg.com). From github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0.
  Licence text in `LICENSE.txt`.
- `kaykit-skeletons/` — KayKit Skeletons Character Pack 1.0, same author, from
  github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0. Licence text in `LICENSE.txt`.
- `quaternius/` — by Quaternius (quaternius.com), fetched from the author's uploads on
  poly.pizza, each listed there as CC0 1.0: `Wolf.glb` (poly.pizza/m/P1gU3Qkr9r),

  `Slime.glb` (/m/LyjSUKHKnh),
